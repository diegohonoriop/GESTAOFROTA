# Gestão de Frota (C# / .NET)

Aplicação de consola desenvolvida em C# para controlo de veículos, listagem, pesquisa e atualização de quilometragem com validação de regra de negócio.

## Funcionalidades atuais
- Cadastro de veículos (placa, modelo, ano e quilometragem inicial)
- Listagem de veículos cadastrados
- Pesquisa por placa ou modelo (sem diferenciar maiúsculas de minúsculas)
- Atualização de quilometragem bloqueando valores menores ou iguais à KM atual

## Tecnologias
- C# / .NET
